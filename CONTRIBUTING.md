# Como contribuir

Obrigado por ajudar a melhorar o SeguraMinhasNotas.

1. Abra uma issue descrevendo o problema ou a mudança proposta.
2. Crie uma branch pequena e focada.
3. Preserve o suporte a macOS 13 e não introduza permissões de Acessibilidade, gravação de tela ou monitoramento de entrada.
4. Execute `./scripts/check.sh` e `./scripts/build-app.sh`.
5. Explique no pull request como validou comportamento, acessibilidade e múltiplos monitores.
